# Unit Converter

A simple and responsive web-based Unit Converter built using HTML5, CSS3, and JavaScript.

## Day 15 Web Development Task

The objective of this project is to build a converter for length and weight units such as meters, feet, kilograms, and pounds.

## Features

- Convert length units
- Convert weight units
- Live conversion while typing
- Dropdown selection for units
- Responsive design
- Simple and user-friendly interface
- Results rounded to four decimal places
- Supports multiple unit types

## Supported Length Units

- Meter
- Kilometer
- Foot
- Mile

## Supported Weight Units

- Kilogram
- Gram
- Pound
- Ounce

## Technologies Used

- HTML5
- CSS3
- JavaScript
